name: status-line
description: Prints the current session context status line
---

Prints the current session context status line showing token counts and percentage.

## Instructions:
1. Identify the current session's Conversation ID from your context metadata.
2. Run the status command in terminal by passing the current Conversation ID: `status-line-monitor --status --conversationId <current_conversation_id>`
3. Output ONLY the exact status line text returned by the command. Do not add any explanations, headers, formatting, or greeting.
